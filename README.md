# Monday - Step 1 (Glowing wave UI)

1. Create a new empty GitHub repo.
2. Upload ALL files from this folder (keep the .github folder!) to the main branch.
3. Open the Actions tab -> "Build APK" -> wait for the green tick.
4. Open the finished run -> Artifacts -> download Monday-debug-apk -> unzip -> install the .apk.
5. Tap the waves to wake Monday.
